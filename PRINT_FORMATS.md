# Shipping Print Formats

Added to Shipping Management:
- Print Shipping Label
- Print Invoice
- Both open a clean print window and invoke browser print.
- Label contains Carbonova branding, ship-to details, farmer ID, shipment ID, shipping mode, tracking and package contents.
- Invoice contains invoice/shipment numbers, bill-to/ship-to details, package products, quantity, unit price, total, shipping mode, tracking and status.

Before production, connect invoice values, tax fields, company address/GST details, and product data to the backend billing/shipping records.
